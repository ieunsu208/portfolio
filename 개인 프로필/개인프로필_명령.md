반드시 Figma 로그인 계정이 `jennycorazon0808@gmail.com`인지 확인하고, `uiuxa0520@gmail.com` 계정은 사용하지 마.

파일이 정상적으로 열리는지 확인한 뒤 다음 항목으로 읽기·편집 권한을 검사해줘.

- 페이지와 레이어 목록을 읽을 수 있는지
- Design 편집 도구가 활성화되어 있는지
- Frame 도구를 선택할 수 있는지
- 새 페이지 및 스타일 생성 기능이 활성화되어 있는지

권한 검사 중에는 파일 내용을 실제로 변경하지 말고, 선택한 도구는 Escape로 해제해줘.
현재 Figma MCP가 다른 계정에 연결되어 있다면 권한 판단에 사용하지 말고 Playwright 브라우저 기준으로 확인해.
검사가 끝나면 로그인된 계정, 읽기 가능 여부, 편집 가능 여부, 파일 변경 여부를 간단히 보고해줘.

## 개인 프로필 작업 이어가기

1. 위 계정·권한 검사를 먼저 완료한다. 계정이 다르면 `jennycorazon0808@gmail.com`으로 브라우저에서 로그인한 뒤 다시 검사한다.
2. Figma의 `개인 프로필` 페이지에서 `1-수정` 프레임을 연다. 이 프레임 안의 `썸네일`, `개인 정보`, `구성` 레이어를 작업 기준으로 삼는다. 탑바는 `1-수정 → 개인 정보 → 탑바`에 있다.
3. 요청받은 부분의 피그마 레이어와 현재 코드를 대조한 뒤 `개인 프로필` 폴더의 파일만 수정한다. 불필요한 화면 캡처를 반복하지 않는다.
4. 수정 후 해당 화면과 동작을 확인하고, 변경한 파일과 확인 결과를 보고한다. 피그마 파일 자체의 변경은 별도 요청이 있을 때 진행한다.

## 현재 구현 상태

- [index.html](./index.html)에 썸네일(`#thumbnail`), 개인 정보(`#about-me`), 구성(`#composition`) 프레임이 있다. 각 프레임 너비는 1920px이다.
- [style.css](./style.css)는 썸네일, [profile.css](./profile.css)는 개인 정보와 탑바, [composition.css](./composition.css)는 구성 프레임을 담당한다. 이미지와 글꼴은 각각 `assets/`, `fonts/`에 있다.
- [script.js](./script.js)는 휠·드래그에 따른 프레임 이동, 메뉴 링크 이동, 현재 페이지 표시, 파란 꽃 단추의 메뉴 접기·펼치기를 처리한다.
- 프레임 높이는 썸네일 950px, 개인 정보 1050px, 구성 2017px이다. 탑바는 개인 정보 프레임과 함께 올라오다가 화면 상단 50px, 오른쪽 111px 위치에 머문다.
- 사용자가 지정한 탑바의 바·단추 겹침은 34px이다. 현재 CSS는 바 너비 579px, 단추 시작 위치 545px로 반영되어 있다. 이 변경은 수치 확인만 했으므로 다음에 탑바를 다룰 때 `1-수정` 프레임과 시각적으로 다시 대조한다.
- 실행 방법은 [상위 README](../README.md)의 `실행` 항목에 있다.
