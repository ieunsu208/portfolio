파일이 정상적으로 열리는지 확인한 뒤 다음 항목으로 읽기·편집 권한을 검사해줘.

- 페이지와 레이어 목록을 읽을 수 있는지
- Design 편집 도구가 활성화되어 있는지
- Frame 도구를 선택할 수 있는지
- 새 페이지 및 스타일 생성 기능이 활성화되어 있는지

권한 검사 중에는 파일 내용을 실제로 변경하지 말고, 선택한 도구는 Escape로 해제해줘.
현재 Figma MCP가 다른 계정에 연결되어 있다면 권한 판단에 사용하지 말고 Playwright 브라우저 기준으로 확인해.
검사가 끝나면 로그인된 계정, 읽기 가능 여부, 편집 가능 여부, 파일 변경 여부를 간단히 보고해줘.

## 메인페이지 구현 순서

1. 위 계정·권한 검사를 먼저 완료한다. 계정이 다르면 `jennycorazon0808@gmail.com`으로 브라우저에서 로그인한 뒤 다시 검사한다. 계정을 확인할 수 없으면 피그마 작업을 진행하지 않는다.
2. Figma의 `웹디자인 60%` 페이지에서 `메인` 프레임을 연다. 매 단계에서 구현할 섹션의 레이어와 크기, 텍스트, 이미지 자산을 확인한다.
3. 한 번에 한 섹션씩 `메인페이지` 폴더의 웹 코드에 구현한다. 기존 섹션은 유지하고, 다음 섹션이 완성되면 화면과 자산 로딩을 확인한다.
4. 각 단계가 끝날 때 구현한 섹션과 남은 섹션을 보고한다. 피그마 파일 자체의 변경이 필요한 경우에는 별도 요청을 받는다.

## 현재 작업 상태

- 1섹션: `Frame 10`의 1920×1080 히어로와 상단 `탑바`를 [index.html](./index.html), [style.css](./style.css)에 구현했다.
- 다음 단계: `Frame 243`부터 시작하는 2섹션을 확인하고 구현한다.
- 원본 이미지와 아이콘은 `assets/`, 웹 글꼴은 `fonts/`에 있다. 새 섹션에서도 기존 자산과 코드를 먼저 확인한다.
