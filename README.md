# 이은수 포트폴리오

[Figma 포트폴리오 디자인](https://www.figma.com/design/XzM3FRAyKsoytzg6MZLKAQ/)의 썸네일, 개인 정보, 구성 프레임을 구현한 정적 웹페이지입니다. 각 프레임의 너비는 1920px이며 높이는 원본 디자인에 맞췄습니다.

## 실행

```sh
python -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173/`을 엽니다.

아래로 드래그하거나 휠을 내리면 개인 정보 프레임이 썸네일 위로, 구성 프레임이 개인 정보 위로 올라옵니다. 드래그를 멈추면 현재 위치가 유지되고, 반대로 움직이면 이전 프레임이 다시 나타납니다. 프레임 높이가 화면보다 길면 다음 프레임이 올라오기 전에 현재 프레임의 나머지 부분을 볼 수 있습니다.

탑바는 개인 정보 프레임과 함께 올라오다가 화면 위에서 40px, 오른쪽에서 40px 위치에 고정됩니다. 구성 프레임에서도 계속 보입니다. 파란 꽃 이미지를 누르면 메뉴가 왼쪽에서 오른쪽으로 접히고 다시 누르면 펼쳐집니다.

썸네일의 화살은 20px 위아래로 움직이는 동작을 다섯 번 반복합니다. 움직임 줄이기 설정이 켜져 있으면 애니메이션을 실행하지 않습니다.
